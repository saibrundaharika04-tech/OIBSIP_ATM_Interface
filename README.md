# OIBSIP - ATM Interface

## 📖 Project Description
The ATM Interface is a Java-based application developed as part of the Oasis Infobyte Internship Program. It simulates the basic operations of an ATM, allowing users to securely manage their bank account through a simple console-based interface.

## ✨ Features
- User Login
- Check Balance
- Deposit Money
- Withdraw Money
- Transaction History
- Exit System

## 🛠️ Technologies Used
- Java
- IntelliJ IDEA
- Object-Oriented Programming (OOP)

## 🚀 How to Run
1. Open the project in IntelliJ IDEA.
2. Compile and run `Main.java`.
3. Log in using your credentials.
4. Perform ATM operations such as balance inquiry, deposit, withdrawal, and view transaction history.

## 📂 Project Structure
- `Account.java`
- `Transaction.java`
- `Login.java`
- `ATM.java`
- `Main.java`
